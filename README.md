# Hello Power Apps Code Apps

A simple "Hello World" demonstration of [Power Apps Code Apps](https://learn.microsoft.com/en-us/power-apps/developer/code-apps/overview) - Microsoft's code-first approach to building enterprise applications on the Power Platform.

## What are Power Apps Code Apps?

Power Apps Code Apps let developers build custom web applications using popular frameworks (React, Vue, Angular) while leveraging the Power Platform's enterprise capabilities:

- **Microsoft Entra authentication** out of the box
- **Access to 1,500+ Power Platform connectors** via JavaScript
- **Managed platform policies** (app sharing limits, Conditional Access, DLP)
- **Simplified deployment and ALM** through the Power Platform

## Prerequisites

Before you begin, ensure you have the following installed:

- [Node.js](https://nodejs.org/) (LTS version, 18.x or higher)
- [Visual Studio Code](https://code.visualstudio.com/)
- [Git](https://git-scm.com/)
- [Power Platform CLI (PAC CLI)](https://learn.microsoft.com/en-us/power-platform/developer/cli/introduction)

### Installing PAC CLI

```bash
# Using npm (cross-platform)
npm install -g @microsoft/power-platform-cli

# Or using dotnet
dotnet tool install --global Microsoft.PowerApps.CLI.Tool
```

### Power Platform Requirements

- A Power Platform environment with Code Apps enabled
- Power Apps Premium license (for end users)
- Request access to the early access preview at https://aka.ms/paCodeAppsEAP

## Getting Started

### 1. Clone the Repository

```bash
git clone <repository-url>
cd hello-power-apps-code-apps
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Authenticate with Power Platform

```bash
pac auth create
```

This will open a browser window for Microsoft Entra authentication.

### 4. Initialize the Code App (if not already done)

```bash
pac code init --displayName "Hello World" --description "A simple Hello World Power Apps Code App"
```

This creates the `power.config.json` file that connects your app to Power Platform.

### 5. Run Locally

```bash
npm run dev
```

This starts both the Vite development server and the PAC CLI server. Open http://localhost:3000 in your browser.

### 6. Build and Publish

```bash
# Build the app
npm run build

# Publish to Power Platform
pac code push
```

## Key Concepts

### SDK Initialization

The Power Apps SDK must be initialized before making any data calls:

```typescript
import { initialize } from '@microsoft/power-apps/app';

useEffect(() => {
  const init = async () => {
    await initialize();
    // SDK is now ready
  };
  init();
}, []);
```

### Adding Data Sources

Connect to Power Platform data sources using PAC CLI:

```bash
# Add Dataverse table
pac code add-data-source -a dataverse -t account

# Add a connector
pac code add-data-source -a connector -c <connector-name>
```

Generated models and services are placed in `/generated/services/`.

### Running Both Servers

The development setup runs two servers:
- **Vite** (port 5173): Hot module replacement for React
- **PAC CLI** (port 3000): Power Platform SDK server

## Important Notes

- **React Version**: Power Apps SDK requires React 18.2.0 specifically
- **Port Requirement**: The SDK currently requires the app to run on port 3000
- **Preview Status**: Code Apps are currently in preview
